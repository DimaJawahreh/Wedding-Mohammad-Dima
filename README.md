# Mohammad & Dima — Wedding Invitation

A luxury digital wedding invitation. Mobile-first, Arabic-first, ready for Vercel.

## Edit wedding details

All names, dates, venue, Arabic text, music, and image paths live in one file:

`src/config.ts`

Replace the song at `public/assets/music/wedding.mp3`.
Replace the couple photo at `public/assets/images/couple.jpg` when you have it.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Import the repo in Vercel. Framework: Vite. Share the URL on WhatsApp.
